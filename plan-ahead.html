GitHub publishing setup
1. Go to github.com/settings/tokens → "Generate new token (fine-grained)"
2. Set Repository access → Only select repositories → pick your plan-ahead repo
3. Set Repository permissions → Contents → Read and write
4. Set short expiration (90 days recommended); copy the token
5. Paste below. Token is stored in your browser only — never sent to anywhere except api.github.com.
Security: token has commit access to the selected repo. Revoke anytime at github.com/settings/tokens. Use fine-grained scope, never classic.
